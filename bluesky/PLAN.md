# Blue Sky Demo Plan

## Vision

**From static argument analysis to agentic public deliberation:** represent collective viewpoints as autonomous agents that can interact, challenge, revise, and influence one another.

Pipeline:

`Arguments -> Viewpoint Clusters -> Viewpoint Agents -> Interaction -> Emergent Opinion Dynamics`

## Demo scope

Version 1 deliberately stays small and deterministic.

- 3 collective viewpoint agents
- 1 institutional information agent
- explicit arguments as the grounding substrate
- argument-level interactions: support, attack, challenge, provide evidence
- state variables: position and strength
- round-by-round state snapshots
- one visible belief/position revision caused by new evidence

## Non-goals

- No LLM role-play
- No automatic clustering yet
- No personal/organizational agents yet
- No claim that the hand-written update rules are a validated social model
- No optimization of institutional persuasion

## Why this demo exists

The goal is not to prove a finished model. It is to make the Blue Sky idea concrete enough to discuss, critique, and write about.
